## 1. 背景与目标

### 1.1 业务背景【来源】

岳阳爱达兴智能科技与江苏高铂尔智能科技需要一套贯通**采购、销售、生产制造、库存、存货核算、供应链协同**的一体化系统，并与 U8C 财务系统对接。业务方案明确要求：

- 以订单为主线，打通采购、销售、生产、库存与财务；
- 建立供应商资格审核、分类、档案与交付协同；
- 通过交付计划、送货、样品送检、异常管理提升供应商交付质量；
- 以集团总计划、生产指令单、BOM、计划排产、日/周计划、投料单组织生产；
- 以库存单据、盘点、预警和存货核算保证账实一致；
- 将存货凭证、应收应付单据传递至 U8C。

### 1.2 现状问题【来源 + 原型决策】

| 问题 | 影响 | 产品回应 |
| --- | --- | --- |
| 采购、库存、生产、销售数据分散 | 订单状态不可视，交付异常发现晚 | 统一业务总图与跨模块台账 |
| 供应商交付与来料质量缺少协同 | 缺料、逾期、质量问题重复发生 | 交付计划、送货、样品、异常与绩效 |
| 计划与执行脱节 | 计划变更无法快速传导到工单与投料 | 集团计划 → 指令 → 排产 → 日计划 → 投料 |
| 库存与财务口径不一致 | 账实不符、凭证滞后 | 出入库单据、核算凭证、U8C 同步 |
| 追溯依赖人工台账 | 质量问题定位慢、召回范围不清 | 序列号正向追溯、批次反查 |
| 管理指标靠报表汇总 | 异常发现滞后 | 总览、大屏、KPI、预警与下钻 |

### 1.3 产品目标

1. **业务闭环**：从供应商交付到客户出库、从生产计划到成品入库，关键单据可关联、可追踪。
2. **异常前置**：缺料、逾期、质量、设备异常在总览与大屏可见，并能下钻处理。
3. **操作可信**：每次关键操作有明确结果、状态变化和反馈；数据在页面间保留。
4. **角色可用**：不同角色能在同一平台快速找到待办、异常与明细。
5. **可演进**：当前为可交互原型，后续可在不改页面的前提下接入真实后端。

### 1.4 成功判据（可观察）

- 一条采购订单可以走完“下单 → 到货 → 入库 → 库存增加”的完整路径；
- 一条销售订单可以走完“下单 → 出库 → 库存扣减 → 凭证生成”的完整路径；
- 一次生产报工可以更新工单进度，并在有不良时生成质量问题；
- 输入序列号可以直接打开追溯档案；
- 页面跳转后，前一步新增或修改的数据仍然存在；
- 关键页面无死链、无死按钮，空态、错误态、重复提交均有反馈。

## 4. 产品模型与核心流程

### 4.1 业务总图

```text
供应商协同 → 采购管理 → 库存管理 → 生产制造 → 销售管理 → U8C 财务
      ↑            ↑           ↑            ↑           ↑
      └── 交付计划 / 送货 / 样品 / 异常 ── 质量 / 追溯 / 设备 ──┘
```

### 4.2 主流程：订单到交付

```text
客户订单（销售）
  → 集团总计划
  → 生产指令单
  → BOM 确认 / 计划排产
  → 日计划 / 周计划
  → 投料单 / 生产领料
  → 生产报工 / 质量检验
  → 成品入库
  → 销售出库
  → 销售发票 / 收入确认
  → U8C 应收单
```

关键共用对象：销售订单、生产指令、工单、序列号/批次、库存、检验单、出库单、发票。

### 4.3 采购到入库

```text
供应商审核 → 采购订单 → 交付计划 → 送货 → 到货单
  → 全部/部分/拒收入库 → 库存增加 → 采购发票 → 结算 / 暂估
  → 应付单 → U8C
```

异常路径：逾期未到货、数量短缺、质量拒收、单据缺失、发票差异。

### 4.4 生产到入库

```text
集团总计划 → 生产指令单 → BOM 确认 → 计划排产
  → 日/周计划 → 投料单 → 生产领料 → 报工
  → 检验 → 不合格处置 → 成品入库
```

### 4.5 销售到收款

```text
销售订单 → 生产备货 → 销售出库 → 销售发票
  → 收入确认 → 应收单 → U8C → 收款核销
```

### 4.6 主数据与编码【来源】

| 对象 | 规则 |
| --- | --- |
| 单位 / 部门 / 人员 | 采用 HR 编码同步 |
| 供应商分类 | 2 位，如整车 01、物料 02、外协 03、服务 04 |
| 供应商编码 | 分类 2 位 + 3 位流水 |
| 存货（产品） | 18 位机号编码 |
| 物料 / 物料分类 | 基础档案模块统一维护 |
| 产品 / 工序 | 基础档案同步显示 |

> 真实企业的编码规则、分类字典与流水长度需在实施阶段确认。【TBD】

## 5. 功能需求

### FR-01 生产总览

**目的**：为制造运营经理提供当班生产、计划达成、质量、设备与物料齐套的统一视图。

**入口与角色**：登录后默认页；运营经理、车间主管。

**页面结构**：
1. 页头：工作日期、班次、实时状态、刷新、导出日报、供应链总览入口；
2. 8 个 KPI：当班产出、计划达成率、FTT、OEE、WIP、平均节拍、设备稼动率、缺料工单；
3. 作业线流程：机加 → 装配 → 测试 → 包装；
4. 产线负荷表：完成/计划、进度、FTT、OEE；
5. 计划达成环图与统计条；
6. 分时产出、7 日趋势、各产线 DPU；
7. 异常与预警时间线、关键物料齐套、产品流动目视。

**关键规则**：
- KPI 卡片可点击下钻到对应模块；
- 产品流动行点击打开抽屉，展示工序履历，并可进入追溯；
- 异常按严重度着色，缺料与设备停机优先展示；
- 刷新按钮显示加载态，完成后反馈刷新时间。

**状态与异常**：
- 无异常时时间线显示空态；
- 刷新失败（真实后端场景）需提示并保留旧数据【Assumption, TBD】。

**验收要点**：
- 8 个 KPI 数值与页面内明细一致；
- 点击任一 KPI 能到达对应页面；
- 产品流动抽屉可打开，追溯链接携带序列号；
- 导出 CSV 包含页面上展示的产线数据。

### FR-02 供应链总览

**目的**：统一呈现采购、销售、库存、生产与 U8C 的供应链运行状态。

**页面结构**：
1. 8 个 KPI：采购在途、待交付订单、库存金额、交付准时率、本月采购额、本月销售额、应付余额、U8C 凭证同步；
2. 业务总图：供应商协同、采购、库存、生产、销售、U8C；
3. 采购/销售月度趋势与 14 日交付准时率；
4. 供应链待办；
5. 交付异常表、库存预警表；
6. U8C 凭证同步表与统计。

**关键规则**：
- 业务总图节点可直达对应模块；
- 交付异常行打开抽屉，可进入采购订单；
- 库存预警行跳转库存预警页签并过滤；
- U8C 失败凭证可重新推送，状态更新并持久化；
- 数据刷新显示加载态。

**验收要点**：
- 6 个业务节点均可点击且目标页面存在；
- 交付异常与库存预警可下钻；
- U8C 重试后状态由“失败”变“已同步”。

### FR-03 车间大屏

**目的**：在车间现场以低交互、高可读方式展示当班产出、计划、异常与停机。

**页面结构**：LED 指标、深色 KPI、4 列看板（待生产/生产中/待检验/已完工）、停机 Top、异常时间线、当前节拍。

**关键规则**：
- 支持全屏/退出全屏；
- 每 30 秒更新时间水印；
- 看板卡片点击查看工单详情；
- 大屏数据为只读展示，不在此页执行写操作。

**异常**：全屏 API 不可用时按钮给出提示【Assumption, TBD】。

### FR-04 计划管理

**目的**：将需求转化为月/周/日计划，锁定 D+3，并发布到车间。

**页面结构**：
1. KPI：本月计划、本月完成、D+3 锁定、计划变更；
2. 计划流程：需求接收 → 月计划 → 周计划 → 日计划 → 班次工单 → 计划发布；
3. 三页签：D+3 锁定计划、本周计划、本月计划；
4. 当日产线排程甘特；
5. 计划预警、排产规则。

**关键规则**：
- D+3 锁定，D+7 滚动【来源/原型决策】；
- 计划发布需选择范围、日期、发布对象与备注；
- 发布后反馈“已发布”并写入操作日志；
- 计划预警按逾期/缺料/产能不足分级；
- 甘特展示产线、产品、数量与时间窗。

**异常**：无计划时显示空态；发布失败保留原状态并可重试【Assumption, TBD】。

**验收**：
- 三个页签数据独立；
- 发布计划弹窗可完成并反馈；
- 甘特与台账数据一致；
- 导出计划 CSV 成功。

### FR-05 生产制造

**目的**：把集团总计划拆解为生产指令、BOM、排产、日/周计划、投料与入库。

**页面结构**：
1. KPI：集团总计划、生产指令单、投料齐套率、生产异常；
2. 8 步流程：集团总计划 → 生产指令单 → BOM 确认 → 计划排产 → 日/周计划 → 投料单 → 生产领料 → 成品入库；
3. 六页签：集团总计划、生产指令、BOM 与变更、排产与日周计划、投料与领料、成品入库与异常；
4. 生产进度跟踪、BOM 齐套提示。

**关键规则**：
- 仅“已评审”的集团计划可生成生产指令；
- 生成日计划时自动生成投料单，并回写指令状态；
- BOM 变更需提交工程变更单，变更单进入评审；
- 模糊物料（未确认项）需在投产前确认；
- 成品入库需检验合格或按让步接收规则处理【Assumption, TBD】。

**异常**：齐套率不足、BOM 模糊、计划冲突、入库检验未完成。

**验收**：
- 生成指令后指令列表新增且集团计划状态变化；
- 生成日计划后投料单新增；
- BOM 变更提交后列表新增；
- 进度表与工单数据一致。

---

### FR-06 生产执行

**目的**：在车间执行工单、工位作业、报工、停机与在制跟踪。

**页面结构**：KPI、工位链（按产线切换）、工单台账（状态筛选）、当班停机、报工记录、分时产出、停机明细。

**关键规则**：
- 报工数量 = 合格 + 不良；输入数量时自动联动；
- 不良数 > 0 时生成质量问题；
- 报工回写工单完成数与状态；
- 工单状态：已排程、生产中、待料、预警、已完成；
- 支持打印流转卡；
- 工单抽屉展示工序进度与最近报工。

**异常与边界**：
- 数量为 0 或非数字时不允许提交；
- 重复报工需按真实接口做幂等【Assumption, TBD】；
- 工单已完成时禁止继续报工【TBD】。

**验收**：
- 报工后工单进度增加、报工记录新增；
- 不良数 > 0 时质量页出现新问题；

### FR-08 采购管理

**目的**：覆盖供应商、采购订单、到货、入库、退货、发票、结算与暂估。

**页面结构**：
1. KPI：本月采购额、在途订单、待入库、待结算；
2. 五页签：供应商档案、采购订单、到货与入库、退货与发票、结算与暂估；

**关键规则**：
- 供应商必须先审核通过才能合作；

- 采购订单状态：已下单、部分到货、已到货、交付逾期；

- 拒收数量生成退货单或进入待处理【Assumption, TBD】；
- 发票与结算分离，支持暂估与回冲；
- 采购订单可多选，批量导出/批量到货登记；

**验收**：
- 创建订单后列表新增；

### FR-10 库存管理

**目的**：保证库存账实一致，支撑采购、生产、销售与核算。

**页面结构**：KPI、4 个仓库卡、六页签（实时库存、入库单据、出库单据、调拨与盘点、库存预警、库龄分析）、其他入库/出库、调拨、盘点、阈值设置。

**关键规则**：
- 库存状态：正常、预警、缺料、呆滞；
- 低于安全库存预警；高于最高库存或长期无动销标记呆滞；
- 其他入库增加库存与金额；其他出库扣减库存与金额；

- 支持多选物料批量生成采购申请；
- 库存台账可勾选、导出、查看近 5 次出入库。

**异常**：出库超过库存、同仓调拨、盘点数量为负、最高库存低于最低库存。

**验收**：
- 其他入库后库存数量与金额增加；
- 其他出库后库存减少；
- 盘点差异与单据一致；
- 阈值修改后预警状态更新。

### FR-12 存货核算

**关键规则**：
- 核算方法：先进先出（演示口径）【原型决策】；
- 单据来源：采购入库、成品入库、销售出库、生产领料、其他出入库；

## 6. 跨模块共享规则

### 6.1 数据保留与联动

| 规则 | 要求 |
| --- | --- |
| 跨页保留 | 新增订单、报工、判定、记账等操作在页面跳转后仍存在 |
| 刷新保留 | 浏览器刷新后仍保留当前演示数据 |
| 重置 | 用户可主动恢复初始演示数据，重置后不可恢复 |
| 深链接 | 支持页签、搜索词、表格容器、序列号、批次、新建动作 |
| 全局搜索 | 支持页面与业务对象统一检索 |
| 操作日志 | 成功操作自动记录，可查看、可清空 |
| 通知 | 已读状态跨页保留；点击直达业务页面 |

### 6.2 状态与色调

统一使用第 9.3 节状态字典；状态色调：绿色完成/正常，黄色进行中/预警，红色异常/失败，蓝色计划/待办，灰色停用/草稿。

### 6.3 单据与编号

- 原型使用固定演示单号，保证跨页一致；
- 生产化要求：单号唯一、不可复用，按业务类型 + 日期 + 序列生成；
- 具体前缀、长度、是否含组织/车间编码由实施确认。【TBD】

### 6.4 数量、金额与单位

| 对象 | 规则 |
| --- | --- |
| 成品/物料数量 | 整数；单位按主数据 |
| 金额 | 万元，保留 1~2 位小数（按页面展示） |
| 百分比 | 1 位小数 |
| OEE | 时间开动率 × 性能开动率 × 合格率【来源/行业口径】 |
| FTT | 一次合格数 / 投入数 |
| DPU | 下线缺陷数 / 下线数量 |

四舍五入与尾差处理在正式核算中需财务确认。【Assumption, TBD】

### 6.5 库存计算（演示口径）

```text
可用库存 = 期初 + 采购入库 + 其他入库 + 调拨入 + 盘盈
         - 生产领料 - 销售出库 - 其他出库 - 调拨出 - 盘亏
```

原型以单条库存记录简化多仓/批次维度；生产化需支持仓库、库位、批次、序列号维度。

### 6.6 质量判定

- 检验结果与不合格处置必须记录责任人与意见；
- 让步接收、报废等重大处置需审批；【Assumption, TBD】
- 不合格批次应冻结，未放行不得出库；
- 追溯数据应覆盖关键件批次与工艺参数。

### 6.7 审计与权限

- 原型记录成功操作日志，用于演示可追溯；
- 生产化需记录操作人、时间、对象、前后值、理由；
- 权限至少区分查看、编辑、审批、导出、配置；
- 关键操作（报废、让步接收、期末结账、重置）需二次确认。

### 6.8 数据保留

- 追溯数据保留 10 年【原型参数，Assumption, TBD】；
- 财务凭证与审计日志按企业合规要求保留；
- 具体期限以财务/法务确认。【TBD】
